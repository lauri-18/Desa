## Nombre del proyecto
Huella energética de la nube
## Descripción
En esta práctica el equipo construye una página web donde cada persona captura su uso digital
semanal. Una inteligencia artificial estima la energía y las emisiones que genera, explica quién paga
ese costo y propone acciones. El equipo debe verificar las suposiciones de la IA con fuentes.

## Objetivos de aprendizaje
Que el alumno reconozca el consumo energético de los servicios digitales como un costo
externalizado, estime su propia huella digital con apoyo de IA y evalúe críticamente las suposiciones
de esa estimación.

## Material utilizado
Computadora con navegador y celular para revisar el tiempo de pantalla.

Cuenta de Make del curso. La IA usa la conexión Make&#39;s AI Provider; no se necesita API
key.

Repositorio de GitHub para publicar la página.
