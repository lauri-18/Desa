## Nombre del proyecto
Calculadora de huella ecológica

## Descripción
En esta práctica el equipo construye una página web con un cuestionario sobre alimentación,
transporte, energía, consumo y residuos. Una inteligencia artificial estima la huella y propone
acciones. Después el equipo compara el resultado con la calculadora oficial de Global Footprint
Network.
## Objetivos de aprendizaje
Que el alumno calcule y compare su huella ecológica, identifique qué hábitos la elevan y proponga
estrategias económicas y personales para reducirla, evaluando la precisión de una estimación
hecha con IA.

## Material utilizado
Computadora con navegador.

Cuenta de Make del curso. La IA usa la conexión Make&#39;s AI Provider; no se necesita API
key.
